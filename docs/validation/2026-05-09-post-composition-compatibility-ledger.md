## Disposition Definitions

| Disposition | Meaning |
| --- | --- |
| Keep | Proven live consumer or required public compatibility |
| Uplift now | Live migration surface that should move to the composition-era contract |
| Verify | Evidence suggests the surface is probably valid, but needs focused confirmation before changing |
| Remove | Stale path with no proven live consumer |
| Historical only | Valid historical reference, not current behavior |
| Needs design | Potential issue that changes a public contract |
